PhoneProof design system

Material 3 structure, "Signal blocks" look: white cards on a soft cool-grey canvas, one teal-blue interaction family, and one big colour block per screen for the verdict. Source of truth: styles.css. Turn on Dev Mode to inspect any component, or use Copy as prompt to build it in Jetpack Compose.

Foundations

Color

OKLCH tonal ramp from seed #0B6E8A. Every fill is shown with its paired foreground; all text pairs are ≥ 4.5:1 by calculation. Status colours are the only saturated hues outside primary, and each carries one meaning.

Typography

One family, Nunito Sans. Rounded terminals give warmth; 800 weight only on display and headline. Body stays 400 for reading; numbers use tabular figures.

Shape

Soft, chunky geometry. Cards and sheets use large (32); buttons and chips are pills.

Elevation

Tonal first: a card is white on the grey canvas, with no shadow. Only floating things (menus, FAB, sheets, dialogs) get a soft shadow. Never a border and a shadow on the same card.

State layers

An overlay of the content colour at fixed opacities. Focus also draws a 2px ring with a 2px gap.

Spacing

4dp grid. Semantic roles keep the calm rhythm: related items 8, sections 24, major blocks 40, screen gutter 20.

Motion

Purposeful only: state changes and screen entries. No decorative loops; spinners stop under reduced motion.

Icons

Inline SVG sprite, Material-outlined geometry with round caps to match Nunito. Glyph 24, touch target 48. Never emoji.
